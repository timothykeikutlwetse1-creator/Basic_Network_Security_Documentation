**Network Security Checklist**

Use this checklist when reviewing basic network security practices in an authorised environment.

**Access Control**

•	[ ] Change default administrative credentials.

•	[ ] Use strong, unique passwords.

•	[ ] Enable multifactor authentication where supported.

•	[ ] Remove access for accounts that are no longer required.

•	[ ] Restrict administrative privileges.

**Network Protection**

•	[ ] Configure firewalls using approved security rules.

•	[ ] Secure Wi-Fi with modern encryption.

•	[ ] Separate guest networks from internal systems.

•	[ ] Disable unnecessary services and open ports.

•	[ ] Protect network management interfaces.

**Systems and Data**

•	[ ] Install security updates regularly.

•	[ ] Use appropriate endpoint protection.

•	[ ] Encrypt sensitive data and communications.

•	[ ] Back up important data and test restoration procedures.

•	[ ] Store credentials securely.

**Monitoring and Incident Response**

•	[ ] Review relevant security logs and alerts.

•	[ ] Investigate suspicious login activity.

•	[ ] Maintain a documented incident-reporting procedure.

•	[ ] Know how to contact the authorised IT or SOC team.

•	[ ] Record incidents and document corrective actions.

**Final Review**

Record any identified gaps, assign responsibility for corrective actions and review progress. Do not perform tests or make changes to a network without permission.

**Purpose**
This checklist supports a basic review of network security controls. It does not replace a formal security audit or a comprehensive risk assessment.
